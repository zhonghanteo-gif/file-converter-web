# Universal File Converter & ZeroBlur Studio (Vercel Frontend)

Ultra-fast, globally distributed frontend hosted on Vercel CDN.
All conversions, chunked uploads, and FFmpeg video processing are bridged to the live Render backend (`https://universal-file-converter-xmxl.onrender.com`).

### Deploy to Vercel (1-Click):
1. Push this folder to a GitHub repository (e.g. `file-converter-web`).
2. Go to [vercel.com/new](https://vercel.com/new).
3. Import your repository and click **Deploy**.
